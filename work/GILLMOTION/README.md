GILLMOTION / seven independent Windows VST3 effects, version0.11.0.

GILLBRAKE: captured beat-length tape stop/start. GILLWIRE: phone/radio coloring. GILLGHOST: breath-like extra voice. GILLTRAIL: pitched feedback delay. GILLMETAL: ring-modulated character. GILLSTUTTER: 1-3 detected syllables on a BPM grid with a rising envelope and alternating pan. GILLCROWD: offline pitch/formant/time variation across4-24 synthetic group voices. Six presets each.

WIRE/GHOST/TRAIL/METAL process live; all seven can capture up to12seconds and render a stereo24-bit WAV. BRAKE/STUTTER/CROWD leave the original audio untouched and build a drag-ready effect. DIRECT OFF removes the original center voice from applicable effects. Captures are embedded in project state. Dragged WAVs must travel with the FL project. STUTTER ends at the selected vocal onset; others start there. Host tempo is used when present, otherwise manual BPM. Sample-grid duration rounding is at most half a sample; tempo changes inside an exported clip do not stretch it afterward. Detector boundaries remain editable, not word recognition. Crowd voices are transformed copies, not separately recorded performers.

All direct paths report0additional latency; intentional delay/voice offsets are part of the effect. LIVE/PRO does not remove interface or DAW buffer latency.
